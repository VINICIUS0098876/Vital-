# Vital - Plataforma de Telemedicina

**Vital** é uma plataforma inovadora de telemedicina, criada para transformar a experiência do usuário em consultas médicas online, proporcionando acessibilidade, praticidade e eficiência. O principal objetivo do projeto é oferecer uma solução tecnológica completa que conecte pacientes e profissionais de saúde, eliminando barreiras geográficas e facilitando o acesso à saúde de qualidade.

---

## 💡 Sobre o Projeto

Neste repositório estão presentes **exclusivamente os códigos do Back-End** da plataforma Vital. Toda a lógica de negócio, comunicação com o banco de dados, autenticação, agendamento de consultas, gerenciamento das consultas online e integração com o chatbot inteligente estão implementados no backend.

O sistema foi projetado para se integrar a diversos clientes, incluindo:
- **Frontend Web:** desenvolvido em React, oferecendo uma interface moderna e responsiva para usuários.
- **Aplicativo Mobile:** desenvolvido em Kotlin, proporcionando uma experiência completa para dispositivos Android.

---

## 🚀 Principais Diferenciais

- **Agendamento de Consultas:**  
  Permite aos pacientes agendar consultas de maneira simples, visualizando disponibilidade dos profissionais e escolhendo o melhor horário.

- **Consultas Online:**  
  Facilita o atendimento médico remoto, possibilitando que consultas sejam realizadas via plataforma, com segurança e qualidade.

- **Chatbot Inteligente:**  
  Um assistente virtual integrado ao sistema para suporte imediato, esclarecimento de dúvidas, auxílio no agendamento e orientação ao paciente.

---

## 🛠️ Tecnologias Utilizadas no Back-End

- **Node.js:**  
  Plataforma utilizada para execução do servidor, garantindo alta performance e escalabilidade.

- **Express:**  
  Framework para Node.js que facilita a criação de APIs RESTful, gerenciamento de rotas e middlewares.

- **MySQL:**  
  Banco de dados relacional para armazenamento seguro e estruturado das informações de usuários, consultas, agendas e interações.

- **Prisma:**  
  ORM moderno para Node.js, utilizado para manipulação eficiente dos dados no MySQL, garantindo agilidade e segurança nas operações.

---

## 🖥️ Tecnologias para Integração com Outros Clientes

**Frontend Web:**  
- **React:**  
  Utilizado para o desenvolvimento da interface web, proporcionando uma experiência intuitiva e amigável ao usuário.

**Mobile:**  
- **Kotlin:**  
  Linguagem utilizada para desenvolvimento do aplicativo Android, entregando robustez e ótima experiência em dispositivos móveis.
